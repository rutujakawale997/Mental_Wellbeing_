Troubleshooting Guide:

  • FastAPI Server Status: Is your backend running? Verify by terminal command uvicorn main:app --port 8000 --reload.
  • Local endpoint check: Visit http://127.0.0.1:8000/ in your browser. It should say ["Welcome"].
  • Mixed Content Blocks: If this frontend is loaded over https://, the browser will block requests to http://127.0.0.1:8000. Run index.html locally via a local HTTP server or the file:// protocol.
  • Model File Check: Make sure the Mental_Health_Model.pkl file is in the folder where you launched uvicorn.
